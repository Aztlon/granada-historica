# M10.5 — Controlled geometry wave 2

Status: **prepared for private historical and spatial review on 2026-10-02**
Publication state: research only; `public_application_import: false`
Review state: all six promoted geometries are `in_review`

## Purpose

Wave 2 re-examines the 14 entities deferred by wave 1 and promotes only the
subset with enough evidence for a deliberately limited representation. It does
not claim a surveyed c. 1550 plan. The canonical decision and control register
is
[`data/research/c1550/m10.5-geometry-wave-2.json`](../data/research/c1550/m10.5-geometry-wave-2.json),
generated by
[`scripts/assemble-m10-5-geometry-wave-2.ts`](../scripts/assemble-m10-5-geometry-wave-2.ts).

## Six promoted hypotheses

| Feature | Representation | Controls | Explicit limits |
| --- | --- | --- | --- |
| `gate.fajalauza` | surviving-site point | surviving fabric, archaeological context, and historical wall connection | no towers, court, attached wall sections, or repair phases |
| `water.acequia-real-alhambra` | retained main axis | Generalife/Torre del Agua fabric and Christian-period continuity | no Darro intake, secondary branches, reservoirs, or unphased repairs |
| `water.acequia-aynadamar` | retained main axes | 1538 water ordinances and published urban/topographic controls | no complete rural intake or inferred uncontrolled branches |
| `water.acequia-gorda` | retained main axis | 1538 regulation and hydrological/topographic corridor | no Realejo branch, other distributors, channel width, or later works |
| `water.acequia-cadi` | retained main axis | 1531 ordinances, 1533 lease, and southern corridor controls | no Aguas Blancas intake, outer payments, intakes, bifurcations, or unmapped losses |
| `water.acequia-romayla` | retained main axis | 1538 regulation and published Avellano/Sabika alignment | no Zacatín, Bib-Rambla, San Francisco, or Corral del Carbón branches |

Each geometry copies the c. 1492 coordinates into an independent `c1550.*`
variant. This is a constrained continuity hypothesis, not inherited proof. Each
record has at least two documented controls, an exclusion list, a separate
period narrative, and a new `in_review` audit.

The three period titles that previously carried incidental state wording were
normalized on promotion: **Acequia Real de la Alhambra**, **Acequia de
Aynadamar**, and **Acequia Gorda**. Period condition and administration remain
in the appropriate narrative and evidence sections.

## Reproduction and review

```powershell
npm run m10:5:geometry:2
npx tsx scripts/assemble-m10-5-candidate.ts
npm run validate:data
npm test
```

`npm run m10:5:assemble` rebuilds all four source tranches, the evidence
preparation register, both geometry waves, and the combined candidate. A future
edit must preserve the registered exclusions or revise the control register and
audit together. Historical review is owner-led by the project historian; this
stage assumes no institutional partner.
